# Сводка изменений

## 1. Исправление логики расчёта доступности поставщика

### Проблема:
Поставщик, который выходит в среду (01.04), отображался как доступный к заказу во вторник (31.03).

### Решение:
Функция `get_next_supplier_delivery_date()` теперь корректно возвращает `is_available=False`, если сегодня не является днём выхода поставщика.

**Логика:**
- Если `min_days_until_order == 0` → поставщик доступен сегодня
- Если `min_days_until_order > 0` → поставщик недоступен, следующий доступный день через N дней

**Тесты:**
```
Сегодня ПН (0):
- Поставщик Ср (2) → Доступен=False ✓
- Поставщик ПН (0) → Доступен=True ✓
- Поставщик ПТ (4) → Доступен=False ✓

Сегодня ВТ (1):
- Поставщик Ср (2) → Доступен=False ✓

Сегодня СР (2):
- Поставщик Ср (2) → Доступен=True ✓
```

## 2. Блокировка формы заказа при недоступном поставщике

### Изменения в `templates/app.html`:

Добавлена проверка поля `'Доступен для заказа'` из ответа API:

```javascript
const isAvailable = result.data['Доступен для заказа'];
if (!isAvailable) {
    orderForm.style.display = 'none';
    // Показываем сообщение с датой следующего доступного дня
} else {
    orderForm.style.display = 'block';
}
```

**Визуальное уведомление:**
- Красная плашка с текстом: "⚠️ Поставщик недоступен для заказа сегодня"
- Указание следующего доступного дня: "Следующий доступный день: ДД.ММ.ГГГГ"

## 3. Счётчик уведомлений показывается только при наличии непрочитанных

### Изменения в `templates/app.html`:

```javascript
// Показываем бейдж ТОЛЬКО если count > 0
if (count > 0) {
    badge.textContent = count > 99 ? '99+' : count;
    badge.classList.remove('hidden');
} else {
    badge.classList.add('hidden');
}
```

**Дополнительно:**
- Ограничение максимума: `99+` при большом количестве
- Обновление счётчика происходит:
  - При загрузке страницы (`DOMContentLoaded`)
  - Каждую минуту (`setInterval`)
  - После отметки уведомления как прочитанного

## Как проверить:

1. **Проверка доступности поставщика:**
   - Найти товар с поставщиком, у которого день выхода ≠ сегодня
   - Форма заказа должна быть скрыта
   - Показать красное предупреждение с датой

2. **Проверка счётчика:**
   - Открыть страницу с непрочитанными уведомлениями → бейдж виден
   - Отметить все как прочитанные → бейдж исчезает
   - Подождать 1 минуту → автообновление

3. **Проверка даты:**
   - Сегодня ПН, поставщик выходит в СР → дата заказа = СР, доступно = False
   - Сегодня СР, поставщик выходит в СР → дата заказа = СР, доступно = True
